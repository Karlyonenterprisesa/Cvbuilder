# Cvbuilder
Adivision CV Builder (Alcartel Digital Vision CV Builder) é uma plataforma digital para construir, em poucos passos, um Currículo Vitae e uma Carta de Apresentação profissionais, em formato A4, prontos a guardar em PDF — tudo no próprio telemóvel, sem necessidade de Internet.  "Ferramentas que simplificam o processo, currículos que abrem portas."
